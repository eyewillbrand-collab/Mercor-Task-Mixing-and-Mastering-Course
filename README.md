# Mixing and Mastering Interactive Course

Seven practice modules plus optional dynamics, EQ and local PCM16 WAV measurement laboratories. Audio stays in the browser; only uncompressed signed 16-bit RIFF/WAVE is supported (mono/stereo, 8–96 kHz, 30 seconds maximum, 10 MiB maximum). Sample peak and pooled RMS are not LUFS or true peak. Course completion is an unverified local practice summary.

Tests: `node --test tests/*.test.js`; browser tests: `npm ci && npx playwright install chromium && npm run test:browser`.
